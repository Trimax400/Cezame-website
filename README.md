# Cézame — Application Mobile (Showcase)

Bienvenue sur le dépôt de présentation de **Cézame**, une application mobile conçue pour aider les aidants du quotidien (notamment en CESU) à organiser plus efficacement leurs journées de travail et leurs trajets.
